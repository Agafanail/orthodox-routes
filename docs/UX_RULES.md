# UX rules v0.1

## Passenger flow

1. Open app.
2. Find church on map/search.
3. Open church page.
4. See trips/routes.
5. Tap “Мне нужно место”.
6. Fill 5 fields max.
7. Wait for driver answer.
8. If accepted, see contact and WhatsApp button.

## Driver flow

1. Register by phone.
2. Fill profile.
3. Choose church.
4. Create one-time trip or recurring route.
5. Receive requests.
6. Accept/decline.
7. Contact opens after acceptance.

## Church flow

1. Register by email.
2. Create/claim church card.
3. Fill simple info.
4. Optional: update schedule.

## UI priorities

- Every important action is a large button.
- Avoid dropdowns with huge lists on mobile.
- Use search + suggestions.
- Do not ask for exact home address.
- Prefer pickup hubs.
- Show verification state clearly.
- Avoid church-political recommendations; show factual jurisdiction/language only.
