Orthodox Routes · эталонные экраны

Сохранённый визуальный эталон канонической Design System V2. Учтены утверждённые поправки: карта вернулась в верх каталога вместе с плавающим поиском и фильтрами, лист со списком получил скругление сверху, карта на странице храма убрана и открывается нажатием на адрес, миниатюры из карточек убраны, заглушка утверждена в финальном виде.

Это эталонный макет, а не production UI или production-код. Данные условные. Onest — утверждённый шрифт V2; сохранённый HTML намеренно не загружает шрифты или другие ресурсы из внешней сети.

Что изменено во всех экранах сразу

ЗелёныйТолько primary-кнопка, активный пункт навигации, выбранный объект и статус «Подтверждено». Убран из иконок заголовков, чипов времени, кнопок в карточках, «Назад» и «Изменить».
Три уровня действийPrimary (заливка) → Secondary (белая, нейтральная граница 3,61:1) → Quiet (только текст). Раньше все второстепенные действия были зелёными.
Значения вместо диапазоновРадиусы: 8 (статусы) / 12 (контролы) / 16 (карточки) / 28 (мобильный лист) / 999 (только таблетки). Отступы 4·8·12·16·24·32·48. Семь кеглей вместо семнадцати.
Интерактивная цельМинимум 44 × 44 px. Компактный визуальный контейнер 36–40 px сохраняет невидимую интерактивную область не меньше 44 × 44 px.
Решающие данные — 15 pxДата, время, число мест, место встречи подняты с 12–13 px и получили основной цвет текста. Текста мельче 12 px не осталось.
ИзображенияВ шапке страницы храма — фотография, а при её отсутствии заглушка (утверждённая, см. конец документа). В карточках списков изображений нет.
КартаВ каталоге — вверху экрана, поиск и фильтры плавают над ней. На странице храма отдельной карты нет: она открывается нажатием на адрес, вместе с маршрутом.
Формы метокСтатус — плашка 8 px; тип объекта — нейтральная таблетка; относительное время — обычный текст, не плашка.
Границы контроловВезде #7D8A80 (3,61:1) вместо декоративных 1,24–1,51:1.
ИконкиУбраны из заголовков секций и из кнопок с однозначными подписями.

Экран 2 · мобильный

Страница храма, верх

  • Шапка с изображением сохранена. При наличии снимка это фотография на 260 px. При её отсутствии — заглушка на 168 px: плоская геометрия, два тона из палитры продукта, без золота, без орнамента и без попытки выглядеть фотографией. Меньшая высота — часть сообщения: заглушка не претендует на место снимка.
  • Заглушка различается по храмам: оттенок выбирается детерминированно по идентификатору, поэтому список перестаёт выглядеть как одна картинка, размноженная пять раз.
  • Устранено дублирование службы: ближайшая служба — в шапке как решение «идти или нет», список ниже назван «Другие службы» и начинается со следующей.
  • Primary во всю ширину, «Могу подвезти» — нейтральной вторичной кнопкой. Раньше две одинаково зелёные кнопки 50/50 конкурировали.
  • Плитки дат без рамок — снят один уровень вложенности контейнеров (было три).
  • Уточнены обязательные элементы IA §9: отдельной карты на странице нет; адрес открывает «Карту и маршрут». Дата обновления расписания и предупреждение о возможных изменениях сохранены.

Экран 6 · desktop

Страница храма и транспортная доска

  • Действия перенесены в закреплённый сайдбар, как требует IA §29.2. Это одновременно решает две проблемы: пустая правая колонка и уезжающая при прокрутке главная кнопка.

Изображение, когда фотографии нет

  • Крупный кадрированный купол с крестом. Плоско, три тона из палитры, без золота и без орнамента. Купол и барабан совпадают по краям и разделены только тоном.

Чего здесь намеренно нет

Не менялись: оттенок зелёного, почти белый холст, отсутствие церковного декора, состав пары «Нужна поездка / Могу подвезти», три пункта нижней навигации, маркер-капля на карте, текстовые статусы, состав сущностей, правила приватности и модель ролей. Каноническая IA V2 включает утверждённые поправки к компоновке и терминологии. Не менялась длина воронки создания просьбы — это продуктовое решение, которое стоит проверять отдельно.

Миниатюры из карточек убраны по вашему решению. Если доля храмов с настоящими фотографиями со временем окажется высокой, к этому стоит вернуться — но тогда с миниатюрой справа, чтобы левый край текста оставался единым.
