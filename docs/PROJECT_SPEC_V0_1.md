# ТЗ v0.1 — «Православные маршруты»

## Цель

Создать работающий PWA-сервис, который помогает православным людям без машины добраться до храма через регулярные маршруты и разовые поездки прихожан.

## Роли

### Пассажир

- регистрируется по телефону;
- видит храмы на карте;
- открывает карточку храма;
- видит ближайшие поездки и регулярные маршруты;
- нажимает «Попросить место»;
- получает ответ водителя;
- после принятия видит контакт водителя и кнопку WhatsApp.

### Водитель

- регистрируется по телефону;
- заполняет профиль: имя, фото по желанию, район выезда, телефон/WhatsApp;
- видит храмы на карте;
- создает разовую поездку;
- создает регулярный маршрут;
- получает заявки пассажиров;
- принимает или отклоняет заявку;
- управляет своими поездками и маршрутами.

### Представитель храма

- регистрируется по email;
- создает или запрашивает управление карточкой храма;
- заполняет: название, локацию, юрисдикцию, языки, расписание, контакты;
- может обновлять карточку, если claim подтвержден админом.

### Админ сервиса

- проверяет новые храмы;
- подтверждает представителей храмов;
- модерирует жалобы;
- может скрыть храм, поездку, маршрут или пользователя.

## Основные сущности

- User
- Church
- ChurchClaim
- DriverProfile
- PassengerProfile
- Route
- Trip
- RideRequest
- Notification

## Главные экраны

1. Главная / карта храмов.
2. Поиск храма.
3. Карточка храма.
4. Создание/редактирование карточки храма.
5. Профиль водителя.
6. Профиль пассажира.
7. Создание разовой поездки.
8. Создание регулярного маршрута.
9. Заявка пассажира.
10. Уведомления.
11. Админ-панель.

## Карточка храма

Вкладки:

1. Как добраться
   - ближайшие поездки;
   - регулярные маршруты;
   - видимые водители, связанные с храмом;
   - кнопка «Мне нужно место»;
   - кнопка «Могу подвезти».

2. Расписание
   - регулярное расписание;
   - исключения;
   - дата последнего обновления.

3. О храме
   - название;
   - юрисдикция;
   - языки богослужения;
   - адрес;
   - карта;
   - кнопка «Открыть в Google Maps»;
   - контакты храма;
   - статус: подтверждено приходом / не подтверждено.

## Уведомления v0.1

- in-app notifications — всегда;
- push через Firebase Cloud Messaging;
- email как резерв;
- Telegram bot как резерв для подключивших;
- WhatsApp-кнопка после принятия заявки;
- без SMS и без WhatsApp Business API.

## Ограничения v0.1

Не делать:

- платежи;
- пожертвования;
- записки;
- рейтинги;
- сложную маршрутизацию;
- автоматическое построение оптимального маршрута;
- нативные приложения.
