# Orthodox Routes MVP / Православные маршруты

PWA-сервис для взаимного подвоза православных людей к храмам.

Главная задача v0.1: человек без машины может найти храм, увидеть маршруты/поездки и попросить место; водитель может создать разовую поездку или регулярный маршрут; храм может вести простую карточку, но продукт не зависит от активности прихода.

## Технологии

- Next.js + TypeScript + Tailwind CSS
- Firebase: Auth, Firestore, Storage, Cloud Messaging
- Google Maps JavaScript API
- Telegram Bot API для резервных уведомлений
- Vercel для деплоя

## Локальный старт

1. Установить Node.js 20.9+.
2. Создать проект Next.js или использовать этот каркас.
3. Скопировать `.env.example` в `.env.local` и заполнить ключи.
4. Запустить:

```bash
npm install
npm run dev
```

## Первый рабочий релиз

В v0.1 делаем только:

- публичную карту храмов;
- карточку храма;
- регистрацию пользователей;
- профиль водителя/пассажира;
- создание разовой поездки;
- создание регулярного маршрута;
- заявку пассажира на место;
- принятие/отклонение заявки водителем;
- in-app + push + email + Telegram-уведомления;
- простую админ-панель для проверки храмов.

Не делаем в v0.1:

- платежи;
- заказы записок;
- WhatsApp Business API;
- SMS-уведомления;
- нативные iOS/Android приложения;
- рейтинги;
- сложную оптимизацию маршрутов.
